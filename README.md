# Genetic_Algorithms
Currently completed two toy projects to understand the fundamentals behind genetic algorithms. These projects included maximising a binary string and searching through random words to produce the string "hello world".

My next goal is to attempt to build another toy project in preperation for a genetic algorithm that minimize price from a shopping list. It takes users' preferences such as the amount of protien, carbohydrates and calories they wishn to consume in a given week and outputs the products that are required to satisfy those requests.
